The intended workflow

Create. Protect. Verify.

The workflow below describes the design being built and verified. Automated backup collection is not currently active.

01

Create a recovery copy

Create a consistent PostgreSQL archive on the owner's VPS, with UTC timestamps and integrity metadata.

02

Store an encrypted copy

Encrypt the archive on the VPS before uploading it directly to the owner's Google Drive.

03

Prove that it restores

Download and decrypt a saved copy, then check its recovery in a separate temporary database.

A limited Google permission

Access to backup files.

The integration requests drive.file. It is intended to create, read, update and delete only the backup files it creates, and check available account storage. It does not request Gmail access.

Requested scope

https://www.googleapis.com/auth/drive.file

You choose the Google account and approve access in Google's authorization screen.
