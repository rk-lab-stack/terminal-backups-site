# Terminal backup information site

Static public information for a personal PostgreSQL backup utility under development.
This repository is intended to contain only the public site files listed below.

- index.html: purpose, current development status and intended workflow.
- privacy.html: Google-data access, storage, retention and deletion disclosures.
- terms.html: personal-project usage information.
- site.css: shared self-contained styles, without external fonts or JavaScript.
- .nojekyll: serve the static files without Jekyll processing.

## Proposed hosting

Repository: rk-lab-stack/terminal-backups-site (public, separate from the private application).
Expected address after Pages is enabled: https://rk-lab-stack.github.io/terminal-backups-site/
This address is a proposed deployment target, not confirmation that the site is live.

Use Settings > Pages > Deploy from a branch > main > /(root), then Save.
Google OAuth publication and acceptance of the GitHub Pages domain must be checked separately.
Full OAuth domain verification may require DNS ownership that a default github.io subdomain cannot provide.

The application is still being developed. Update these disclosures as the implemented data practices change.
Never upload the application checkout, private configuration, tokens, keys or database archives to this repository.
